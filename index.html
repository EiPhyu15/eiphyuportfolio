PROJECT 01

QR Based Food Ordering System

The QR-Based Food Ordering System is a web application developed to make the restaurant ordering process easier and more efficient. Customers can scan a QR code to view the menu and place their food orders without waiting for staff assistance. The system also allows administrators to manage food items, categories, tables, and orders, while kitchen staff can monitor and update order statuses. This project was developed using HTML, CSS, C#, ASP.NET Core MVC, and SQL Server.
